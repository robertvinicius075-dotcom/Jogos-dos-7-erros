Apresentação do Projeto

Sobre o Projeto Educacional

Este objeto de aprendizagem interativo foi desenvolvido como parte de uma atividade acadêmica do SENAC, combinando conceitos de gamificação, desenvolvimento web e pedagogia ativa.

O objetivo principal desta aplicação é atuar como uma ferramenta lúdico-pedagógica para aprimorar a atenção concentrada, a percepção espacial, a organização de gôndolas e as regras operacionais de reposição (como a metodologia PEPS).
